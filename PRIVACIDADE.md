# Política de privacidade — IA para Pessoas (automação de publicação)

Última atualização: 27/11/2026

O aplicativo **IA para Pessoas** é uma automação pessoal de Marcelo Jacinto Ferreira que publica, no canal do YouTube [IA para Pessoas](https://www.youtube.com/@iaparapessoas), os vídeos gerados neste repositório.

## Quais dados o aplicativo acessa
- Usa a API de Dados do YouTube apenas com a permissão `youtube.upload`, concedida pelo próprio dono do canal, para enviar vídeos, título, descrição, tags e capa **ao canal do próprio dono**.
- Não lê, coleta nem armazena dados de outros usuários, espectadores, inscritos ou comentários.

## Como os dados são guardados
- A credencial de acesso fica guardada como *secret* criptografado do GitHub Actions deste repositório e só é usada pelo workflow de publicação.
- Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

## Como revogar o acesso
O dono do canal pode revogar o acesso a qualquer momento em <https://myaccount.google.com/permissions>.

## Serviços de terceiros
Ao usar este aplicativo, valem também os [Termos de Serviço do YouTube](https://www.youtube.com/t/terms) e a [Política de Privacidade do Google](https://policies.google.com/privacy).
